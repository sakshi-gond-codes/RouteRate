What gets cleaned automatically
  • Title rows above the header are skipped
  • Delimiter detection (comma, semicolon, tab, pipe)
  • +44, 0044, spaces → 44
  • Lists 44, 447 and ranges 4470-4479
  • $0.0123, 0,0123 → 0.0123
  • Excel, ISO, dd/mm/yyyy and text dates
  • Country checked from the prefix dial code

Full vs partial deck

Full A-Z: the file is the vendor's complete price list. Prefixes missing from it are closed on the deck's effective date.

Partial update: only the prefixes in the file change. Everything else keeps its current rate.
